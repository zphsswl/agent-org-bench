# Earlier exploratory study / 前期探索档案

This is a retired, separate study, not part of the main 60-task comparison. It tested three policies on 90 tasks each with different task draws and a weaker control set. Both registered quality comparisons passed; the registered efficiency comparison did not. Those scoped results are retained for provenance and cannot replace the stronger-control main result.
