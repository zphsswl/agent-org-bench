# 2026-11-03：工具型组织策略实验预注册 v4

本轮继承用户“继续实验、不设总预算”的授权。总费用不设置人为研究上限；API实际可用余额、并发和服务健康仍是客观运行条件。所有旧数据和失效结论原样保留，不补齐或拼接旧确认集。全量实验依次完成既定样本，不反复查看确认结果直到显著。

## 研究修正

旧规划任务在12000思考Token下仍经常没有终局答案；继续手算搜索不适合检验实际工具型Agent。本轮改为生成算法/修复程序，再通过确定性受限Python AST解释器执行公开测试。隐藏测试只在模型完成后独立判分，不给调度器反馈。

旧24.65% Token节省不能再解释为组织优势：同样预处理的单体首轮在证据任务上3/3成功且仅9736 Token，五轮自检累计46922；契约路由10588，反而高于强首轮单体。本轮强基线公开测试通过即停止，消除强制重复自检。

## 模型、工具与组织

统一使用环境已配置的deepseek-v4-pro。主实验非思考模式，温度请求/有效值0.3；每单元最多5次逻辑模型调用、12000累计输出Token、32000输入Token估算预检及实际超限标记。总量无预算停止，但达到预定样本即结束本次试验。管理、审计、合并与修复的调用全部计入。相同上限不等于相同实际成本。

5种组织：single_tool（公开测试通过即停的单体）；hierarchy_tool（路由、两个独立工作报告、合并、必要修复）；bazaar_tool（两个隔离完整候选、公开测试和确定性选择）；contract_team（完整程序、独立审计、根据真实公开失败和审计疑点修订）；adaptive_tools（只依公开结构/规则复杂度，确定性选择单体或契约团队，不读取任务类型标签或隐藏答案）。后两者是手写机制原型，不声称学习得到的自治组织或原创理论。路由阈值在模型开发调用前设为25：公开规则叶子数+条件词数+2×依赖词数达到25走团队，否则单体。仅检查公开文本后发现旧默认18会令全部任务走团队，故在任何新模型结果出现前修正；不基于隐藏质量调阈值。

所有组拥有相同公开规格、错误starter、公开examples、语法与公开执行反馈。审计模型给出的预期输出仅为未验证意见，不能标为外部真值。最终质量由私有测试全部通过判断，另报通过比例。程序只在受限AST解释器执行：没有exec/eval、import、文件、网络和shell能力，有限步数/时间/容器规模；不把此解释器称为可执行任意Python的生产安全沙箱。解释器子集会限制外推范围。

## 数据与选择

3族生成型代码修复：版本/来源冲突合并、幂等状态机账本、条件依赖配置规则。规则参数与测试输入按独立seed生成；同一生成语法的新seed仍不是现实仓库分布外验证。

开发：seed=2026110301，split=dev，每族5题，5组织各一次，共15个独立任务、75个运行。若发现基础设施或解释器语义错误，先修复、另存开发目录，不使用确认数据调参。开发中按完整隐藏成功数最多选择一个非基线候选（仅bazaar_tool/contract_team/adaptive_tools），同分依总输入+输出Token少，再按名称排序。选择文件保存源码与结果哈希；确认期间不更改选中候选。

确认：seed=2026110302，split=holdout，每族30题，共90个独立任务。冻结候选、single_tool、hierarchy_tool各一次，共270个运行。确认题目可提前生成，但在选择冻结前不调用模型，不查看其结果来设计策略。运行顺序随机交错，固定外层4并发，内部仍串行。生成seed不控制供应商采样。

## 事先固定的判断

总体为三族等权。全对成功是主质量指标。两个质量比较为“候选减single_tool”“候选减hierarchy_tool”，按任务配对；使用精确符号置换和配对Bootstrap区间，两项Holm校正阈值0.025，差值正且95%区间下界正才能确认相对该对照的质量提升。

效率比较只针对single_tool，容许的成功率退化上界预先定为5个百分点，最小总Token节约为15%。每题若候选成功均值低于基线，则记loss=1；用单侧97.5% Clopper-Pearson上界估计P(loss)，这是成功率下降幅度的保守上界。须loss上界<=0.05，并且按题配对重采样的总Token比95%区间上界<0.85，才能确认本任务分布下的容限效率改进。该5pp容限属于本研究固定判据，不表示现实应用都可接受5pp退化。

质量检验族分配0.025，效率交并检验族分配0.025；两类声明合计家族错误率不超过0.05。n=90且零loss时CP上界约4.02%；n=9不够。Token为资源代理，不能等同费用；另报输入/输出/缓存以及按固定价格表重算的估计费用，不能事后挑某个有利成本指标替代主指标。延迟只描述本实现负载，不作内部并行加速确认。

确认须任务/架构/重复键完整唯一、每组都有90独立题、无未知usage或基础设施污染。缺失或污染不删除坏样本来选赢家。观察Pareto前沿只作描述；没有通过上述门槛就写证据不足。单体也可能是已测条件下最优观察点，不为迫使新架构胜出降低基线。

## 运行健康与后续

外层4并发，服务端额度动态变化不由公开最大并发推断。仅对明确HTTP429拒绝最多重试2次，等待3秒/10秒，每次API尝试均写日志；未知超时/传输失败不自动重试。连续3个最终基础设施错误后锁存停止新派发，迟到成功不解除。逻辑推理调用与HTTP尝试分别记账。模型使用量仍可能产生费用，不自动充值。

若主实验有可解析且非全地板的结果，按预定规则完成确认。随后可在新任务seed、另一推理模式或另一模型上做独立迁移复验；迁移结果不回填或改写本次确认。若需改变候选、任务或门槛，则另立协议和新确认集，不复用已看过的确认来反复优化。
